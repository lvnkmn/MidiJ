# MidiJ

## Description
Beatmatch your MIDI gear. Build hybrid DJ sets/ live sets. 

[Control your midi devices like you would your DJ set](https://www.youtube.com/watch?v=BGQhw35zh9k): cue, control tempo and nudge without noticeable latency, add percussion layers to your DJ set using a drum computer, add melodic layers to a techno set or sync up your hardware to a drummer without the need for a click track. The possibilities are endless.

This app works with any midigear and audiobus apps that receive a midi clock, both on USB-C and lighting devices (all the way down to iOS 15).

Battle-tested in both professional studios and onstage.

Built for performers, producers, and live artists. 

[Available in the appstore](https://apps.apple.com/us/app/midij/id1660370476).
